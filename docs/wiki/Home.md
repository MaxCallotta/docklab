# DockLab Wiki

DockLab 是一款本地优先的分子对接可视化科研平台，将分子预处理、口袋预测、对接计算与 3D 结果分析整合为统一工作流。

## 快速导航

- [Getting Started](Getting-Started.md)
- [Development Guide](Development-Guide.md)
- [FAQ](FAQ.md)

## 核心能力

- 支持 PDB ID、CDXML、SDF、MOL、MOL2、SMILES 输入
- 3D 对接盒子拖拽与参数双向同步
- 自动口袋预测与手动微调
- AutoDock Vina / AutoDock4 对接
- 本地任务持久化与结果导出

## 获取软件

从 GitHub Releases 下载 `CaddPlatform.exe`，双击运行即可。exe 已内置 Python、RDKit、OpenBabel 与对接引擎，无需预装其他软件。
