# Security Policy

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities. Report them privately through GitHub's security advisory feature or by contacting the maintainers directly.

When reporting, include:

- A description of the vulnerability
- The affected version
- Steps to reproduce, if available
- Any suggested mitigation

## Scope

Security reports are evaluated for issues affecting:

- Remote code execution or path traversal
- Unauthorized file access
- Credential or data leakage
- Dependency vulnerabilities in supported releases

## Expectations

Maintainers will acknowledge reports as soon as practical and provide a timeline for resolution. Please allow time for a fix before disclosing the issue publicly.
